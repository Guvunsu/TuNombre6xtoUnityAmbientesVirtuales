# Glass
**Version:** 1.0.0
**Unity Compatibility:** Unity 2021.3 LTS or higher

## Overview

Shader to show glass effect.

## Features

* Shows Glass Effect. 

## Getting Started

1.  **Importing the Package:**
    *   Open your Unity project.
    *   Go to `Window > Package Manager`.
    *   Navigate to "My Assets," find "Glass" and click "Download" then "Import."

2.  **Basic Usage:**
    *   Use Anexas/URP/Glass as shader for your glass material.

## Advanced Usage / Customization
    *   Modify Shader properties in the material.

## Requirements

*   Unity 2021.3+
*   Works with Universal Render Pipeline.
